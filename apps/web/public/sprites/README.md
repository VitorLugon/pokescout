# Pokémon icons

`pokemon-icons.png` is a local snapshot of the public Pokémon Showdown icon sheet:
https://play.pokemonshowdown.com/sprites/pokemonicons-sheet.png

Retrieved 2026-10-14. Sheet 480 × 4110; cells 40 × 30; twelve columns.
Only National Pokédex species positions 1–1025 are used. Forms and TCG prefixes
use a representative base species icon, not a claim about the exact card/form.
Unknown names have no icon. Icons are decorative; original source names remain visible.

Names/aliases in `src/pokemon-sprite-map.json` were generated from public snapshots:
- https://play.pokemonshowdown.com/data/pokedex.json
- https://raw.githubusercontent.com/PokeAPI/pokeapi/master/data/v2/csv/pokemon_species_names.csv

Pokémon and related characters belong to Nintendo, Game Freak, Creatures and
The Pokémon Company. Sprite artwork is credited to the Pokémon Showdown/Smogon
sprite contributors and original game artists. See https://github.com/smogon/pokemon-showdown-client
and https://github.com/PokeAPI/sprites for the upstream projects and credits.
No external sprite requests occur while browsing PokéScout.
